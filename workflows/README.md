## n8n Workflows

The n8n workflow JSON files used in this project are available below.

- [Gmail Product Recommendation Workflow](../workflows/odi-product-recommendation-gmail.json)
- [Outlook Automated Email Workflow](../workflows/odi-automated-email-system-outlook.json)
- [Customer Feedback Collection Workflow](../workflows/odi-feedback-collection.json)

### How to use

1. Download the desired `.json` file.
2. Open n8n.
3. Select **Import from File**.
4. Upload the JSON workflow.
5. Configure your own credentials and integrations before running the workflow.
